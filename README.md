Sitio estático de marca personal construido con HTML, CSS y JavaScript nativos. No requiere frameworks, instalación ni compilación.

- Educación
- Experiencia laboral
- Proyectos con filtros interactivos
- Trayectoria académica: ORCID, Google Scholar, perfil institucional UNAB y CvLAC
- Contacto por correo electrónico (el teléfono fue omitido)

## Vista previa local
Abre `index.html` en un navegador.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html` y este `README.md` a la raíz del repositorio.
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/(root)`, guarda los cambios.
6. GitHub Pages publicará el sitio y mostrará la URL en esa misma sección.

## Personalización
Los colores están definidos al inicio del bloque CSS como variables (`--paper`, `--ink`, `--accent`, etc.). Puedes cambiar allí la paleta completa.
